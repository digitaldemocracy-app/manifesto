# Assinaturas

Pessoas que assinam o Manifesto da Digital Democracy.

Assinar significa: *li o manifesto e apoio o seu ponto de partida.* Não significa concordar com cada palavra (o texto está aberto a correções) e não cria nenhuma obrigação.

## Como assinar

Assinar é um pull request. Isso mantém o processo simples, sem servidores nem formulários, e deixa um registro público, permanente e verificável: o histórico do git mostra quem adicionou cada linha e quando.

1. Faça um fork deste repositório (ou edite este arquivo direto no GitHub, pelo ícone do lápis: o GitHub cria o fork e o pull request para você).
2. Adicione **uma linha no fim da tabela da lista**. Não edite as linhas de outras pessoas.
3. Abra o pull request. Título: `Signature: <your name>`.
4. Um mantenedor confere a linha e faz o merge. Só isso.

Se preferir não mexer com git, abra uma issue com o modelo **Support / sign**. Um mantenedor adiciona a sua linha por você, citando o número da issue no commit, para que o registro continue verificável.

## O que escrever

| Coluna | Regra |
|---|---|
| Name | Seu nome como você quer que apareça. Nome real é incentivado, mas não obrigatório. |
| GitHub | Seu usuário no GitHub, opcional. Se informado, deve ser a conta que abriu o pull request ou a issue. |
| Where | País, região ou cidade, opcional. Tão amplo ou tão específico quanto você quiser. |
| Date | O dia em que você assinou, `YYYY-MM-DD`. |

Não coloque e-mail, telefone, número de documento nem qualquer outro dado pessoal. Não queremos e não vamos aceitar. Tudo neste arquivo é público para sempre.

## Verificação

- Toda linha foi adicionada por um pull request ou por uma issue. O commit que adicionou a linha e a conta que o fez aparecem no histórico do arquivo no GitHub.
- Um mantenedor só faz o merge de uma linha se o nome nela corresponder ao do pull request (ou da issue), ou se quem assina confirmar no pull request.
- Os mantenedores nunca removem linhas, exceto a pedido de quem assinou, por outro pull request, que também fica registrado.
