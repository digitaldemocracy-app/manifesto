# Signatures

Les personnes qui signent le Manifeste de Digital Democracy.

Signer signifie : *j'ai lu le manifeste et je soutiens son point de départ.* Cela ne veut pas dire être d'accord avec chaque mot (le texte est ouvert à la correction) et cela ne crée aucune obligation.

## Comment signer

Signer, c'est une pull request. C'est peu coûteux, sans serveur ni formulaire, et cela laisse une trace publique, permanente et vérifiable : l'historique git montre qui a ajouté chaque ligne et quand.

1. Faites un fork de ce dépôt (ou modifiez directement ce fichier sur GitHub avec l'icône du crayon : GitHub crée le fork et la pull request pour vous).
2. Ajoutez **une ligne à la fin du tableau de la liste**. Ne modifiez pas les lignes des autres.
3. Ouvrez la pull request. Titre : `Signature: <your name>`.
4. Un mainteneur vérifie la ligne et la fusionne. C'est tout.

Si vous préférez ne pas toucher à git, ouvrez une issue avec le modèle **Support / sign**. Un mainteneur ajoutera votre ligne à votre place, en citant le numéro de l'issue dans le commit, pour que la trace reste vérifiable.

## Quoi écrire

| Colonne | Règle |
|---|---|
| Name | Votre nom tel que vous voulez qu'il apparaisse. Un vrai nom est encouragé, mais pas obligatoire. |
| GitHub | Votre nom d'utilisateur GitHub, facultatif. S'il est indiqué, ce doit être le compte qui a ouvert la pull request ou l'issue. |
| Where | Pays, région ou ville, facultatif. Aussi large ou aussi précis que vous le souhaitez. |
| Date | Le jour de votre signature, `YYYY-MM-DD`. |

N'ajoutez ni adresse e-mail, ni numéro de téléphone, ni numéro de pièce d'identité, ni aucune autre donnée personnelle. Nous n'en voulons pas et nous ne les fusionnerons pas. Tout ce que contient ce fichier est public pour toujours.

## Vérification

- Chaque ligne a été ajoutée par une pull request ou une issue. Le commit qui a ajouté une ligne, et le compte qui l'a fait, sont visibles dans l'historique du fichier sur GitHub.
- Un mainteneur ne fusionne une ligne que si le nom correspond à celui de la pull request (ou de l'issue), ou si le signataire le confirme dans la pull request.
- Les mainteneurs ne suppriment jamais de ligne, sauf à la demande du signataire, par une autre pull request, qui reste elle aussi consultable.

## Liste des signatures

La liste des signatures est unique, dans [SIGNATURES.md](../SIGNATURES.md) à la racine. Signez là-bas, dans n'importe quelle langue.
