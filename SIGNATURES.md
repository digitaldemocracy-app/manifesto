# Signatures

People who sign the Digital Democracy Manifesto.

Signing means: *I have read the manifesto and I support its starting point.* It does not mean agreeing with every word — the text is open to correction — and it creates no obligation.

## How to sign

Signing is a pull request. That keeps it cheap, with no servers and no forms, and it leaves a public, permanent, verifiable record: the git history shows who added each line and when.

1. Fork this repository (or edit this file directly on GitHub with the pencil icon — GitHub creates the fork and the pull request for you).
2. Add **one line at the end of the table below**. Do not edit other people's lines.
3. Open the pull request. Title: `Signature: <your name>`.
4. A maintainer checks the line and merges it. That is all.

If you prefer not to touch git, open an issue with the **Support / sign** template. A maintainer will add your line for you, citing the issue number in the commit, so the record stays verifiable.

## What to write

| Column | Rule |
|---|---|
| Name | Your name as you want it shown. A real name is encouraged, but not required. |
| GitHub | Your GitHub username, optional. If given, it must be the account that opened the pull request or issue. |
| Where | Country, region or city, optional. As broad or as specific as you like. |
| Date | The day you signed, `YYYY-MM-DD`. |

Do not add e-mail addresses, phone numbers, ID numbers or any other personal data. We do not want it and we will not merge it. Everything in this file is public forever.

## Verification

- Every line was added by a pull request or an issue. The commit that added a line, and the account that made it, are visible in the file's history on GitHub.
- A maintainer only merges a line if the name on it matches the pull request (or the issue), or if the signer confirms it in the pull request.
- Lines are never removed by maintainers except at the signer's request, by another pull request, which also stays on record.
