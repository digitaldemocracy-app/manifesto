# Firmas

Personas que firman el Manifiesto de Digital Democracy.

Firmar significa: *he leído el manifiesto y apoyo su punto de partida.* No significa estar de acuerdo con cada palabra (el texto está abierto a correcciones) y no crea ninguna obligación.

## Cómo firmar

Firmar es un pull request. Así es barato, sin servidores ni formularios, y deja un registro público, permanente y verificable: el historial de git muestra quién añadió cada línea y cuándo.

1. Haz un fork de este repositorio (o edita directamente el archivo en GitHub con el icono del lápiz: GitHub crea el fork y el pull request por ti).
2. Añade **una línea al final de la tabla de la lista**. No edites las líneas de otras personas.
3. Abre el pull request. Título: `Signature: <your name>`.
4. Un mantenedor revisa la línea y la fusiona. Eso es todo.

Si prefieres no tocar git, abre un issue con la plantilla **Support / sign**. Un mantenedor añadirá tu línea por ti y citará el número del issue en el commit, para que el registro siga siendo verificable.

## Qué escribir

| Columna | Regla |
|---|---|
| Name | Tu nombre como quieres que aparezca. Se recomienda un nombre real, pero no es obligatorio. |
| GitHub | Tu usuario de GitHub, opcional. Si lo indicas, debe ser la cuenta que abrió el pull request o el issue. |
| Where | País, región o ciudad, opcional. Tan general o tan concreto como quieras. |
| Date | El día en que firmaste, `YYYY-MM-DD`. |

No añadas correos electrónicos, teléfonos, números de documentos de identidad ni ningún otro dato personal. No los queremos y no los fusionaremos. Todo lo que hay en este archivo es público para siempre.

## Verificación

- Cada línea fue añadida mediante un pull request o un issue. El commit que añadió una línea y la cuenta que lo hizo se ven en el historial del archivo en GitHub.
- Un mantenedor solo fusiona una línea si el nombre coincide con el del pull request (o del issue), o si quien firma lo confirma en el pull request.
- Los mantenedores nunca eliminan líneas, salvo a petición de quien firmó, mediante otro pull request, que también queda registrado.

## Lista de firmas

La lista de firmas es única, en [SIGNATURES.md](../SIGNATURES.md) en la raíz. Firma allí, en cualquier idioma.
