# Tanda Tangan

Orang-orang yang menandatangani Manifesto Digital Democracy.

Menandatangani berarti: *saya sudah membaca manifesto ini dan mendukung titik awalnya.* Bukan berarti setuju dengan setiap kata (teksnya terbuka untuk dikoreksi), dan tidak menimbulkan kewajiban apa pun.

## Cara menandatangani

Menandatangani itu lewat pull request. Cara ini murah, tanpa server dan tanpa formulir, dan meninggalkan catatan yang terbuka, permanen, dan bisa diverifikasi: riwayat git menunjukkan siapa yang menambahkan tiap baris dan kapan.

1. Fork repositori ini (atau sunting berkas ini langsung di GitHub dengan ikon pensil: GitHub akan membuatkan fork dan pull request-nya untukmu).
2. Tambahkan **satu baris di akhir tabel daftar**. Jangan menyunting baris orang lain.
3. Buka pull request. Judul: `Signature: <your name>`.
4. Seorang maintainer memeriksa barisnya lalu me-merge-nya. Selesai.

Kalau kamu tidak mau berurusan dengan git, buka issue dengan templat **Support / sign**. Seorang maintainer akan menambahkan barismu, dengan mencantumkan nomor issue di commit, sehingga catatannya tetap bisa diverifikasi.

## Apa yang ditulis

| Kolom | Aturan |
|---|---|
| Name | Namamu seperti yang ingin ditampilkan. Nama asli dianjurkan, tetapi tidak wajib. |
| GitHub | Nama pengguna GitHub-mu, opsional. Jika diisi, harus akun yang membuka pull request atau issue tersebut. |
| Where | Negara, wilayah, atau kota, opsional. Seluas atau sespesifik yang kamu mau. |
| Date | Hari kamu menandatangani, `YYYY-MM-DD`. |

Jangan menambahkan alamat e-mail, nomor telepon, nomor identitas, atau data pribadi lainnya. Kami tidak menginginkannya dan tidak akan me-merge-nya. Semua isi berkas ini publik selamanya.

## Verifikasi

- Setiap baris ditambahkan lewat pull request atau issue. Commit yang menambahkan sebuah baris, dan akun yang membuatnya, terlihat di riwayat berkas di GitHub.
- Maintainer hanya me-merge sebuah baris jika namanya cocok dengan nama di pull request (atau issue), atau jika penandatangan mengonfirmasinya di pull request.
- Maintainer tidak pernah menghapus baris, kecuali atas permintaan penandatangan, lewat pull request lain, yang juga tetap tercatat.
