# हस्ताक्षर

Digital Democracy घोषणापत्र पर हस्ताक्षर करने वाले लोग।

हस्ताक्षर का मतलब है: *मैंने घोषणापत्र पढ़ा है और उसके शुरुआती बिंदु का समर्थन करता/करती हूँ।* इसका मतलब हर शब्द से सहमत होना नहीं है — पाठ में सुधार के लिए हमेशा जगह है — और इससे कोई बाध्यता पैदा नहीं होती।

## हस्ताक्षर कैसे करें

हस्ताक्षर करना एक pull request है। इससे यह सस्ता रहता है, किसी सर्वर या फ़ॉर्म की ज़रूरत नहीं पड़ती, और एक सार्वजनिक, स्थायी, जाँचा जा सकने वाला रिकॉर्ड बनता है: git इतिहास दिखाता है कि हर पंक्ति किसने और कब जोड़ी।

1. इस रिपॉज़िटरी को fork कीजिए (या GitHub पर पेंसिल आइकन से इस फ़ाइल को सीधे संपादित कीजिए — GitHub आपके लिए fork और pull request बना देता है)।
2. नीचे दी गई **तालिका के अंत में एक पंक्ति** जोड़िए। दूसरों की पंक्तियाँ मत बदलिए।
3. pull request खोलिए। शीर्षक: `Signature: <आपका नाम>`।
4. कोई मेंटेनर पंक्ति जाँचकर उसे merge कर देता है। बस इतना ही।

अगर आप git को छूना नहीं चाहते, तो **Support / sign** टेम्पलेट के साथ issue खोलिए। कोई मेंटेनर आपकी पंक्ति जोड़ देगा और commit में issue का नंबर लिखेगा, ताकि रिकॉर्ड जाँचा जा सके।

## क्या लिखें

| कॉलम | नियम |
|---|---|
| Name | आपका नाम, जैसे आप दिखाना चाहें। असली नाम का स्वागत है, पर ज़रूरी नहीं। |
| GitHub | आपका GitHub यूज़रनेम, वैकल्पिक। अगर दें, तो यह वही अकाउंट होना चाहिए जिसने pull request या issue खोला। |
| Where | देश, क्षेत्र या शहर, वैकल्पिक। जितना व्यापक या विशिष्ट चाहें। |
| Date | जिस दिन आपने हस्ताक्षर किए, `YYYY-MM-DD` रूप में। |

ईमेल पते, फ़ोन नंबर, पहचान-पत्र के नंबर या कोई और निजी जानकारी मत जोड़िए। हमें वह नहीं चाहिए और हम उसे merge नहीं करेंगे। इस फ़ाइल में जो भी है, वह हमेशा के लिए सार्वजनिक है।

## सत्यापन

- हर पंक्ति किसी pull request या issue से जोड़ी गई है। कौन-सा commit कोई पंक्ति जोड़ता है और किस अकाउंट ने जोड़ी, यह GitHub पर फ़ाइल के इतिहास में दिखता है।
- मेंटेनर किसी पंक्ति को तभी merge करता है जब उस पर लिखा नाम pull request (या issue) से मेल खाता हो, या हस्ताक्षरकर्ता pull request में उसकी पुष्टि कर दे।
- मेंटेनर कोई पंक्ति नहीं हटाते, सिवाय तब जब हस्ताक्षरकर्ता किसी दूसरे pull request के ज़रिए ऐसा कहे; वह भी रिकॉर्ड में रहता है।
