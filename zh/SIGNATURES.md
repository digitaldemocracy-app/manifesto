# 签名

签署 Digital Democracy 宣言的人。

签名的意思是：*我读过这份宣言，我支持它的出发点。* 这不代表同意每一个字——文本欢迎更正——也不产生任何义务。

## 如何签名

签名就是一个 pull request。这样成本很低，不需要服务器，也不需要表单，同时留下公开、永久、可验证的记录：git 历史会显示每一行是谁在什么时候添加的。

1. Fork 这个仓库（或者直接在 GitHub 上点铅笔图标编辑该文件——GitHub 会替你创建 fork 和 pull request）。
2. 在下方**表格的末尾添加一行**。不要修改别人的行。
3. 提交 pull request。标题：`Signature: <你的名字>`。
4. 维护者核对这一行并合并。就这样。

如果你不想碰 git，请使用 **Support / sign** 模板提交 issue。维护者会替你添加这一行，并在提交说明中注明 issue 编号，这样记录依然可验证。

## 写什么

| 列 | 规则 |
|---|---|
| Name | 你希望显示的名字。鼓励使用真名，但不强制。 |
| GitHub | 你的 GitHub 用户名，可选。如果填写，必须是提交该 pull request 或 issue 的账号。 |
| Where | 国家、地区或城市，可选。可宽泛，也可具体，随你。 |
| Date | 你签名的日期，格式 `YYYY-MM-DD`。 |

不要添加电子邮箱、电话号码、证件号码或任何其他个人数据。我们不需要，也不会合并。这个文件里的一切都将永久公开。

## 验证

- 每一行都是通过 pull request 或 issue 添加的。添加某一行的提交及其账号，都可以在 GitHub 上该文件的历史中看到。
- 只有当这一行上的名字与 pull request（或 issue）相符，或签名者在 pull request 中确认时，维护者才会合并。
- 维护者不会删除任何一行，除非签名者提出请求，并通过另一个 pull request 办理，该请求同样留有记录。

## 签名列表

签名列表只有一份，在根目录的 [SIGNATURES.md](../SIGNATURES.md) 中。请到那里签名，用任何语言都可以。
