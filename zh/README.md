# Digital Democracy（数字民主）
## 为所有人的声音而写的宣言

我们选出一些人，让他们替我们发声。
可是，太多时候，他们不再倾听。

不是因为缺少民主，而是因为缺少工具。

我们今天的民主，诞生于一个民众的声音要靠马匹传递的年代。我们选出一个人，把自己的声音交给他，然后等待——一等就是好几年——才知道这声音有没有送到。今天，我们每个人的口袋里都装着与全世界对话的力量。可我们仍在等待。

在民众的意愿和最终的决定之间，裂开了一道空隙。游说、私利、顺水推舟的沉默，都住在里面。我们不指责任何人：我们指责的是这段距离。

我们要把它缩短。

## 我们的提议

一种新型的民主。它从叠加在现有民主之上开始。它能走多远，不由我们决定——由各地的民众自己决定。而这正是我们的提议。

具体来说，是一个平台：一个开放的、全球性的单一数字系统，任何人、在世界任何地方，都可以提出、辩论和投票——并且在同一块屏幕上，看到自己的社区、自己的国家和整个人类正在决定什么。

它从第一行代码起就在公开中建造，任何一方民众都可以在自己的国家、自己的州、自己的城市采用它——如果他们愿意。没有人被要求加入。而一方民众接着一方民众地累加起来，它让人类做到从未做到的事：组织起来，共同决定属于所有人的事。

在这个平台上：

**一切都看得见。** 提案、论点、计票、规则，以及运行这一切的代码，都是公开而永久的。没有任何东西会在沉默中被抹去。

**你的票属于你。** 始终保密。并且可验证：你可以确认自己的票已被计入。你可以自由地告诉全世界你投了什么——但没有任何人、在任何时候，能强迫你去证明它。于是，愿意公开立场的人可以公开；需要保护的人得到保护。

**每个人只存在一次，分量完全相同。** 一个身份，一张票。没有机器人，没有制造出来的人潮，没有因为喊得更响或付得更多就更有分量的声音。

**每个决定属于它所影响的人。** 社区的事由社区决定。城市的事由城市决定。国家的事由国家决定。而属于所有人的事——气候、海洋、大流行病——由我们所有人共同决定。这不是一个世界政府：而是一个学会共同决定的世界，每一层各在其位。因为地图上的线条划分的是土地，不是兄弟姐妹。

**辩论不是争吵。** 在这里，论点有立场，立场有论点。胜出的是论证最充分的想法，而不是重复最多的那个。

**我们选出最有能力的人，去执行我们共同决定的事。** 负责规划和执行的人由民众选出，在光天化日之下，依据他们做过什么、会做什么。能力是透明的；决定的权力对所有人依然平等。

**有些事情不交付表决。** 每个人的尊严、自由和基本权利，不进入投票箱。多数选择道路；但不选择谁可以走在这条路上。

## 致各机构

我们不是政党。我们没有候选人。我们不取代任何选举、任何议会、任何法院。

我们是一件工具：一幅忠实、持久、可验证的图景，呈现人们在想什么、要什么——供执政者、立法者和审判者使用。没有任何政府被要求听取我们。但愿意听的政府，将以更高的正当性来治理，因为他们会在决定之前，知道自己的民众会怎样决定。

任何当选者，不论来自哪个政党，都可以公开承诺：按照自己的民众在这里的决定来做决定——而所有人都能核验他们是否信守了承诺。

我们不是来取代任何人的。我们是来把那个让各机构得以诞生的东西还给它们：支撑它们的人的声音。

## 为什么是现在

因为夺走我们注意力的技术，也可以把我们的声音还回来。因为已经有人开始了——在阿雷格里港，在台湾，在巴塞罗那——并证明了这是可能的。也因为还没有人向整个世界、在同一时间、把一切摊在阳光下敞开过大门。

如果你曾感到自己的声音在半路上走失，这里有它的位置。

阅读。反对。提议。签名。

让我们一起，组织起这个世界的民主。
