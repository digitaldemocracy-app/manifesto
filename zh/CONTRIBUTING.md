# 参与贡献

这份宣言不属于任何人：它只是一个起点。请更正它、翻译它、改进它。

这里的一切都在这个仓库里公开进行。没有邮件列表，没有私下的频道。issue 和 pull request 就是全部记录。

## 参与方式

| 我想…… | 怎么做 |
|---|---|
| 签署宣言 | 按照 [SIGNATURES.md](SIGNATURES.md) 操作 |
| 修正错别字或失效链接 | 直接提交 pull request |
| 建议修改措辞或观点 | 使用 **Text suggestion** 模板提交 issue |
| 翻译，或审校译文 | 使用 **Translation or review** 模板提交 issue，然后提交 pull request |
| 提问或提出异议 | 先看 [FAQ.md](FAQ.md)；如果里面没有，使用 **Text suggestion** 模板提交 issue，并加上 `question` 标签 |

## 官方文本

- 官方文本是 [../README.md](../README.md) 中的英文版。
- [../pt/README.md](../pt/README.md) 中的葡萄牙语文本是作者的原文，也是所有译文的语义依据。
- 对官方文本的实质性修改（除错别字、语法或链接之外的一切）必须先以 issue 的形式提出，让理由在修改之前就公开。由作者和维护者决定；讨论全程留有记录。
- 每一处修改都要通过 pull request，并至少经一位维护者审阅。`main` 分支受保护；任何人都不能直接向它推送，维护者也不例外。

## 翻译

1. 在 [TRANSLATIONS.md](../TRANSLATIONS.md) 中查看你的语言的进度。如果已经有人在做，请加入他们的 issue，不要另开一个。
2. 使用 **Translation or review** 模板提交 issue。说明是哪种语言、你是否是母语者，以及你是来翻译还是来审校。
3. 从英文文本翻译。遇到有歧义的句子，以葡萄牙语原文来判断含义。保持相同的标题和相同的段落数；不要增加、删除或调换章节顺序。
4. 把文件放在 `<code>/README.md`，文件夹以两位 ISO 639-1 代码命名（`es`、`fr`、`zh` ……）；配套文档放在同一文件夹中，包括 `PRINCIPLES.md`、`FAQ.md`、`NEUTRALITY.md`、`CONTRIBUTING.md`、`SIGNATURES.md` 和 `LICENSE`（如果有官方的知识共享译本）。如果某种语言需要地区变体，使用连字符加地区代码（`pt-PT`、`zh-TW`）。
5. 从右向左书写的语言（阿拉伯语、乌尔都语、波斯语、希伯来语）：把全部文本包在 `<div dir="rtl">` … `</div>` 中，开始标签之后和结束标签之前各留一个空行。参见 [../ar/README.md](../ar/README.md)。
6. 提交 pull request。至少有另一位母语者在 pull request 中批准后，译文才会被标记为 **Reviewed**（已审校）。

欢迎翻译成列出的十种语言之外的语言。这十种只是起点，不是上限。

## 风格

- 短句。平实的词。宣言是要能大声读出来、一再被复述的。
- 保持语气：邀请，而不是指责。我们指责的是距离，不是人。
- 无论用哪种语言，都不支持或攻击任何政党、候选人、政府或国家。

## 行为准则

辩论不是打架。论点有立场，立场也有论点。反对观点，不要针对个人。维护者会关闭变成人身攻击的讨论，对屡教不改者可能封禁其账号。

## 许可

提交贡献，即表示你同意你的贡献以与宣言相同的许可发布，即[知识共享署名 4.0 国际许可协议（CC BY 4.0）](LICENSE)。译者会在译文文件和 git 历史中署名。
