# Подписи

Люди, подписавшие Манифест Digital Democracy.

Подписаться значит: *я прочитал(а) манифест и поддерживаю его отправную точку.* Это не значит соглашаться с каждым словом (текст открыт для исправлений) и не создаёт никаких обязательств.

## Как подписаться

Подпись — это pull request. Так это просто: никаких серверов и форм, а след остаётся публичным, постоянным и проверяемым: история git показывает, кто добавил каждую строку и когда.

1. Сделайте fork этого репозитория (или отредактируйте файл прямо на GitHub через значок карандаша: GitHub сам создаст fork и pull request).
2. Добавьте **одну строку в конец таблицы списка**. Чужие строки не редактируйте.
3. Откройте pull request. Заголовок: `Signature: <your name>`.
4. Мейнтейнер проверит строку и сделает merge. Вот и всё.

Если вы не хотите возиться с git, откройте issue по шаблону **Support / sign**. Мейнтейнер добавит вашу строку сам и укажет в коммите номер issue, чтобы запись оставалась проверяемой.

## Что писать

| Столбец | Правило |
|---|---|
| Name | Ваше имя в том виде, в каком вы хотите его показать. Настоящее имя приветствуется, но не обязательно. |
| GitHub | Ваш логин на GitHub, по желанию. Если указан, это должен быть аккаунт, открывший pull request или issue. |
| Where | Страна, регион или город, по желанию. Настолько широко или конкретно, как вам удобно. |
| Date | День подписи, `YYYY-MM-DD`. |

Не добавляйте адреса электронной почты, телефоны, номера документов и любые другие личные данные. Они нам не нужны, и мы не будем их принимать. Всё в этом файле публично навсегда.

## Проверка

- Каждая строка добавлена через pull request или issue. Коммит, добавивший строку, и аккаунт, который его сделал, видны в истории файла на GitHub.
- Мейнтейнер принимает строку, только если имя в ней совпадает с именем в pull request (или issue) либо если подписавшийся подтвердит это в pull request.
- Мейнтейнеры никогда не удаляют строки, кроме как по просьбе подписавшегося, через другой pull request, который тоже остаётся в истории.
