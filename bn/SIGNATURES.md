# স্বাক্ষর

যাঁরা Digital Democracy ইশতেহারে স্বাক্ষর করেছেন।

স্বাক্ষর করার মানে: *আমি ইশতেহারটি পড়েছি এবং এর সূচনাবিন্দুকে সমর্থন করি।* এর মানে প্রতিটি শব্দে একমত হওয়া নয় — পাঠটি সংশোধনের জন্য উন্মুক্ত — এবং এতে কোনো বাধ্যবাধকতা তৈরি হয় না।

## কীভাবে স্বাক্ষর করবেন

স্বাক্ষর করা মানে একটি pull request। এতে খরচ কম থাকে, সার্ভার বা ফর্ম লাগে না, আর একটি প্রকাশ্য, স্থায়ী ও যাচাইযোগ্য রেকর্ড থেকে যায়: git ইতিহাস দেখায় প্রতিটি লাইন কে কখন যোগ করেছেন।

1. এই রিপজিটরি fork করুন (অথবা GitHub-এ পেন্সিল আইকন দিয়ে সরাসরি এই ফাইল সম্পাদনা করুন — GitHub আপনার জন্য fork ও pull request তৈরি করে দেয়)।
2. নিচের **টেবিলের শেষে একটি লাইন** যোগ করুন। অন্যদের লাইন বদলাবেন না।
3. pull request খুলুন। শিরোনাম: `Signature: <আপনার নাম>`।
4. একজন মেইনটেইনার লাইনটি যাচাই করে merge করেন। ব্যস, এটুকুই।

git ছুঁতে না চাইলে **Support / sign** টেমপ্লেট দিয়ে একটি issue খুলুন। একজন মেইনটেইনার আপনার লাইনটি যোগ করে দেবেন এবং commit-এ issue-র নম্বর উল্লেখ করবেন, যাতে রেকর্ড যাচাইযোগ্য থাকে।

## কী লিখবেন

| কলাম | নিয়ম |
|---|---|
| Name | আপনার নাম, যেভাবে দেখাতে চান। আসল নাম উৎসাহিত করা হয়, তবে বাধ্যতামূলক নয়। |
| GitHub | আপনার GitHub ইউজারনেম, ঐচ্ছিক। দিলে সেটি সেই অ্যাকাউন্টই হতে হবে যা pull request বা issue খুলেছে। |
| Where | দেশ, অঞ্চল বা শহর, ঐচ্ছিক। যত খুশি বিস্তৃত বা নির্দিষ্ট। |
| Date | যেদিন স্বাক্ষর করেছেন, `YYYY-MM-DD` ফরম্যাটে। |

ইমেইল ঠিকানা, ফোন নম্বর, পরিচয়পত্রের নম্বর বা অন্য কোনো ব্যক্তিগত তথ্য যোগ করবেন না। আমরা তা চাই না এবং merge করব না। এই ফাইলের সবকিছু চিরকালের জন্য প্রকাশ্য।

## যাচাই

- প্রতিটি লাইন একটি pull request বা issue-র মাধ্যমে যোগ হয়েছে। কোন commit লাইনটি যোগ করেছে এবং কোন অ্যাকাউন্ট থেকে, তা GitHub-এ ফাইলের ইতিহাসে দেখা যায়।
- মেইনটেইনার কোনো লাইন merge করেন কেবল তখনই, যখন তাতে লেখা নাম pull request-এর (বা issue-র) সঙ্গে মেলে, অথবা স্বাক্ষরকারী pull request-এ তা নিশ্চিত করেন।
- মেইনটেইনাররা কোনো লাইন সরান না, শুধু স্বাক্ষরকারী অনুরোধ করলে, অন্য একটি pull request-এর মাধ্যমে; সেটিও রেকর্ডে থাকে।
